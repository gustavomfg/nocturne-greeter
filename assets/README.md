# Original Nocturne geometry

`nocturne-mark.svg`: two opposed, tapered eclipse crescents. Authored specifically for this project. Transparent vector, 40-unit master, two paths; the rendered mark uses 30–40.5 logical px.

`icons/*.svg`: an original consistent 24-unit system, 1.5-unit strokes, round joins/caps. No icon-font glyphs or external icon assets.

The hero is generated by `shaders/pulse.frag`; no image/video/Blender asset is a runtime dependency. Noto Sans, Adwaita Sans and Adwaita Mono are resolved from the installed system fonts and are not bundled or redistributed.

`docs/screenshots/` contains direct Qt captures, not generated concept images. `before-idle.png` is the inspected first-pass baseline. `final/` contains the art-direction revision.
